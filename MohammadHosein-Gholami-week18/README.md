# Contact App

A React application to manage your Contacts .
You can add , Update and Delete your contacts.

---

# Features

- Add new Contacts
- Edit Contacts
- Delete Contacts
- Responsive design for Desktop and Tablet

---

# Technologies Used

- React.js
- Css
- React Router
- React Hook Form
- Validation Yup
- React Context
- React Reducer
- Local Storage
- React Navigate
