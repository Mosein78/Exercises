# Storage App

A React application to manage your Products .
You can add , Update , Search and Delete your Products.
Also you can Register and Login a new Account.

---

# Features

- Login Form
- Register Form
- Add new Products
- Edit Products
- Delete Products
- Search Products
- Responsive design for Desktop and Tablet

---

# Technologies Used

- React.js
- Css
- React Router
- React Navigator
- React Hook Form
- Validation Yup
- TanStack Query
- Swagger Api
- Local Storage
- Node.js
- Express.js
- UseCustom
- React Hook Form
- React-Loader-Spinner

- React-Icons
